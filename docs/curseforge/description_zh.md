# Forestry Sable Compat

**Sable** 能把一整栋建筑变成会动的物理结构。但 **Forestry: Community Edition** 的机器经不起这一趟：内容物复制或直接消失、多方块控制器里的东西全丢、蜂房永远停在装配时所在的群系。本 mod 修的就是这三件事 —— 纯服务端、无需配置、不加任何方块和物品。

可以随时加进已有的存档，也可以随时移除：本 mod 全部是 Mixin 补丁，不保存任何自己的数据。

## 它修的问题

### 1. 内容物被复制，或者丢失
Sable 把方块搬进 sub-level 之前，会先保存方块实体的完整 NBT，再让方块实体清空自己（`Clearable.tryClear`），最后才拆掉世界里的方块。Forestry 的机器通过 `Container` 声明了 `Clearable`，但实现是个空方法 —— 于是拆方块那一步把机器里的东西（和电路板）掉在了地上，而前一步保存的 NBT 又把同一批东西带进了 sub-level。结果就是地上掉一份、机器里留一份。解除物理化走的是同一段代码，所以反方向一样会复制。

电路板是另一套独立库存，不在 `Container` 视图里，由 Forestry 自己的清理逻辑单独掉落 —— 这也是通用修复 mod 漏掉它的原因。

### 2. 多方块的内容物凭空消失
蜂房组（Alveary）和自动化农场（Managed Farm）的库存不在成员方块上，而在最低成员托管的 `MultiblockController` 里，以 payload 的形式传递。Sable 的 plot 和世界共用同一个 `Level` 与多方块索引，复制过去的 NBT 里锚点仍指向世界侧的控制器 —— 于是 sub-level 里的结构做自校验时，正好找到了"正在被搬走的那台"控制器，直接复用它，并把刚读进来的 payload 抹掉。结构落地后里面是空的。

### 3. 蜂房永远不会离开装配时的群系
Sable 把 sub-level 的方块存在远离世界的 plot 里，并在装配时把锚点群系写进 plot chunk。Forestry 直接查方块所在位置的群系，拿到的是装配时的群系 —— 结构开走、旋转、传送到别的群系后都不会变，温度、湿度、蜜蜂行为全是错的。

## 这个 mod 做了什么

- **在对的时机清空机器。** Sable 要求清空时，Forestry 方块实体现在真的会清空内部库存、所有电路板 socket，多方块还会清空共享的控制器库存。内容物完整保留在 Sable 复制的那份 NBT 里，原位置没东西可掉。可重复调用，无副作用。
- **让 sub-level 侧自己重建控制器。** 只从**复制出来的那份**标签里去掉多方块锚点坐标，plot 侧的结构于是按自己的结构重新校验，从 payload 里 seed 出新控制器，而不是劫持正被搬走的那台。世界侧的方块实体完全不受影响。
- **按结构当前实际位置查群系。** 蜂房、简易蜂房、蜂房组、蜂巢的群系判定，包括温度/湿度缓存和附加模组使用的 climate API，都会先把 plot 坐标投影回世界坐标再查群系。跨群系的大结构里，每个蜂房各拿各的群系；不在 sub-level 里的方块行为完全不变。
- **顺带修正 `/setblock ... replace`** 对 Forestry 机器不清理内容物的偏差。

没有新方块、新物品、配置项或命令；除了 Forestry 本来就会做的群系查询，没有额外每 tick 开销。

## 为什么现成的修复 mod 不够用？

- **Sable Assembly Fix** 只处理"没有实现 `Clearable`"的方块实体。Forestry **实现了**（只是方法体是空的），所以它直接跳过。
- **Sable Fix Mod** 会清 `Container` / `IItemHandler`，能修主库存，但看不到 Forestry 的电路板 socket，也管不到多方块的控制器 payload。

本 mod 用的是 Sable 给原版方块实体用的同一个 `Clearable` 扩展点，再补上多方块锚点修复。可以和 Sable Fix Mod 一起装（已用 1.1.0 实测），但不依赖它。

## 说明与已知限制

- 基于 Sable 2.0.x 开发。它注入的是 Sable 的装配流程，注入点对不上时会直接报错，而不是静默什么都不做 —— Sable 哪天改了这段代码，你会在启动时立刻发现，而不是先坏掉一批库存。
- Managed Farm 和蜂房组走同一套代码，但目前没有单独的 GameTest。
- 只修正 Forestry 的蜂房/蜂房组/蜂巢和 climate 查询；其他按群系判定的 Forestry 逻辑（世界生成、树木、蝴蝶等）没有改动。
- Sable 的 plot chunk palette（草/水的颜色）仍显示装配时的群系，尽管蜂房已经按真实群系报告气候。
- 天气和"能否看到天空"仍来自 Sable 的宿主侧，`isRaining()` / `canBlockSeeTheSky()` 尚未按位置修正。
- 不会追溯修复安装本 mod 之前就已经复制出来的结构。
